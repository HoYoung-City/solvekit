# solvekit

AI와 함께 문제를 이해하고, 작게 풀어 보고, 반복되는 작업을 재사용하기 위한 참고 자료입니다.

**필요한 부분만 참고하세요.** 순서, 분류, 문서 작성, 도구 사용은 상황에 맞게 선택하고 바꿀 수 있습니다.

| 필요할 때 | 열어볼 자료 |
|---|---|
| 전체와 세부를 오가며 생각을 정리하기 | [방법과 도식](METHODS.md) |
| 반복 작업의 의존관계·근거·도식을 관리하기 | [선택적 실행 도구와 명령어](tools/README.md) |
| 현재 작업에 부족한 기능의 외부 자료 찾기 | [작업별 참고 색인](REFERENCES.md) |

큰 흐름을 이해할 수 있는 수준에서 첫 결과를 만들고, 부족한 부분만 자세히 다루며, 개선이 전체 결과에 도움이 되는지 확인하는 접근을 담았습니다.
유사한 경험은 조건을 비교해 재사용하고, 새로운 문제에서 발견한 반복 작업은 필요할 때 자동화합니다.

자료만 읽어도 충분합니다. 도구를 사용한다면 Python 3.10 이상이 필요하며 추가 패키지는 없습니다.
